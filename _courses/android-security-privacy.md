## Module 1: Security Fundamentals

The threat model for mobile apps. What attackers target, how Android's security model protects users, and the security principles that guide every decision.

- [Android Security Best Practises Guide](/guide/android-security-best-practises/)

## Module 2: Secure Storage

How to store sensitive data on Android. EncryptedSharedPreferences, EncryptedFile, Android Keystore, and the DataStore patterns that keep credentials safe.

- [DataStore Done Right — Replacing SharedPreferences](/guide/datastore-done-right/)
- [Encrypted Storage in Android Guide](/guide/android-encrypted-storage-guide/)

## Module 3: Network Security

Certificate pinning, Network Security Config, TLS configuration, and the network-level protections that prevent man-in-the-middle attacks.

- [Android Network Security Guide](/guide/android-network-security-guide/)
- [Network Performance Optimization in Android](/guide/network-performance-android/)

## Module 4: Authentication

Biometric authentication, Credential Manager, passkeys, and the authentication patterns that balance security with user experience.

- [Android Biometric Authentication Guide](/guide/android-biometric-authentication-guide/)

## Module 5: Deep Links and App Links

Intent filters, App Links verification, deep link security, and the patterns that prevent link hijacking and ensure users reach the right destination.

- [Android Deep Links and App Links Guide](/guide/android-deep-links-guide/)

## Module 6: Privacy

Runtime permissions, privacy-first design, data minimization, and the Android privacy features that affect app behavior across API levels.

- [Android Privacy Guide](/guide/android-privacy-guide/)
- [Android 17 Beta 1 — What's New and What You Need to Prepare](/guide/android-17-beta-whats-new/)
